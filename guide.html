YUITO8-22ガイドライン

call_split リミックス
私がリミックスした作品のリミックスに関しては、コメントは不要です。ただしリミックス元のScratcher側にルールがあった場合、そちらが優先です。
info リミックス元が削除された場合
リミックス元のプロジェクトが削除された場合、当該リミックスは削除されませんが、リミックス元のScratcher側から要請があった場合、対応させていただきます。
block 誹謗中傷禁止
誹謗中傷は虚偽の情報で相手を傷つける悪質な行為です。
diversity_1 スク友・スク彼は禁止
Scratchは交流アプリでも、マッチングアプリでもありません。
list スタジオ招待について
スタジオ招待はコメント不要です。
diversity_2 依頼・コラボについて
一切受け付けていません。
hub コンテンツ集について
Github Pagesの制限に達した場合、予告なくコンテンツを削除する場合があります。
warning 免責事項
プロジェクトは予告なく削除、変更する場合があります。
それによる損害について、責任を負いません。
gavel 対応について
もしコメントでクレジット表記の要請や、素材に関する要請
(例えば使ってはいけない素材を使っていた場合など)、その他要請があった場合、速やかに対応させていただきます。
rule それ以外にも
その他Scratchのコミュニティーガイドラインや利用規約に違反する行為も禁止です。
copyright Scratchで共有するプロジェクトとそうじゃないプロジェクトの違い
いらすとやなど、Scratchで使ってはいけないとされているサイトの素材を使用しているプロジェクトは、Scratch上で共有しません。
